# Contribuindo

1. Crie uma branch a partir de `main`.
2. Não inclua `.env`, bancos, logs, uploads ou dados reais.
3. Execute as validações do README.
4. Mantenha mudanças pequenas e explique risco e evidência no pull request.
5. Atualize documentação e testes quando alterar comportamento.

Commits recomendados: `feat:`, `fix:`, `test:`, `docs:`, `refactor:` e `security:`.
