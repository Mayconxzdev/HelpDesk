# Política de segurança

Não abra issue pública com credenciais, dados pessoais, anexos corporativos ou detalhes de exploração.

Para relatar uma vulnerabilidade, entre em contacto com o responsável pelo repositório através do perfil [@Mayconxzdev](https://github.com/Mayconxzdev). Inclua versão, impacto, passos mínimos de reprodução e evidências sanitizadas.

A distribuição é um projeto de portfólio. Não deve ser implantada com dados reais sem revisão de segurança, configuração de produção e validação independente.
